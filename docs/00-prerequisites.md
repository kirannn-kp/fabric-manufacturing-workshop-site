# Prerequisites

## Microsoft Fabric

You need access to the workshop Fabric workspace.
You must be able to create and edit items.
Before the workshop, check that you can:

- Open the workshop workspace.
- Select New item.
- Create or edit a Lakehouse.
- Create or edit an Eventhouse, if enabled.
- Open a semantic model.
- Create or edit a Fabric Data Agent, if enabled.

## Laptop and browser

Bring your laptop and charger.
Use Microsoft Edge or Google Chrome.
Check that you can sign in to:

- Microsoft Fabric
- Microsoft Teams
- GitHub

## Workshop data

Download the two synthetic CSVs and check the filenames and headers using the [dataset steps](onsite-workshop.md#2-download-and-check-the-workshop-data). No cleaning or SAP connection is needed.

## GitHub

For event-provided Copilot access, follow the [screenshot and sign-up steps](onsite-workshop.md#get-github-copilot-access) in the onsite guide. Use the personal GitHub account requested by the join page unless the organizer confirms that your Bosch-managed GitHub account is supported. The Fabric labs can run without Copilot.

## Microsoft Foundry

Microsoft Foundry access is not required for the two Fabric workshop days.
Foundry will be used only for an optional facilitator demonstration.

## Team access

At least one person in each group must have working edit access to the Fabric workspace.
We recommend edit access for every hands-on participant.

## Access problem

If access does not work, share:

- Product name
- Screenshot
- Complete error message
- Time of the error

Share these details privately and redact sensitive information. See [support](../SUPPORT.md).
